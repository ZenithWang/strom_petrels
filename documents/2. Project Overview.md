**2. Project Overview**

本项目研究如何利用 BirdNET 预训练模型生成的音频嵌入，对风暴海燕（Storm-Petrel）的录音片段进行自动声学分类。项目的核心目标是探索这些嵌入是否能够支持对不同类型风暴海燕声音的区分，尤其是成人个体与雏鸟相关叫声之间的分类；同时也会建立一个可靠的“风暴海燕声音 vs 背景声音”基线模型，作为后续成人/雏鸟分类的技术基础。

本项目要调查的问题是：基于声学数据，BirdNET 嵌入能否有效捕捉风暴海燕叫声中的判别特征，并在训练样本有限、背景噪声复杂的条件下实现稳定分类。该问题具有实际意义，因为人工检查长时间野外录音非常耗时，自动分类方法可以提高海鸟监测、繁殖活动分析和长期生态调查的效率。

该主题的重要性在于，它结合了人工智能、生态声学和野生动物保护应用。若模型能够可靠地区分目标声音类别，将有助于研究人员更高效地分析风暴海燕在繁殖季节的活动模式，并为后续更精细的行为或年龄阶段声学分析提供基础。

**3. Related Work**

已有研究表明，深度学习方法已经广泛用于鸟类声音识别和生态声学监测。BirdNET 是其中较成熟的工具之一，它使用大规模鸟类声音数据训练模型，能够对录音中的鸟种进行自动检测和分类。相比从零训练一个深度神经网络，使用 BirdNET 嵌入可以减少对大型标注数据集的依赖。

现有 BirdNET 主要面向鸟种识别，不是专门区分同一物种内部的成人/雏鸟叫声或不同叫声类型。因此，本项目的一个关键挑战是：现有数据是否包含足够可靠的成人/雏鸟标签。如果标签不足，项目将先完成风暴海燕声音检测与背景分类，并把成人/雏鸟分类作为可行性分析或扩展实验。

本项目与现有工作的不同之处在于，它不是简单使用 BirdNET 的最终物种预测结果，而是利用 BirdNET 的中间嵌入作为特征，再训练一个面向特定风暴海燕数据集的小型分类器。这种方法更适合针对特定地点、特定物种和特定录音条件进行定制化建模。

**4. Methodology**

项目将首先整理已有的风暴海燕录音和检测结果，构建训练、验证和测试数据集。音频片段会被统一处理为 48 kHz、单声道、约 3 秒长度的 WAV 文件。正样本来自高置信度风暴海燕检测片段，背景样本从相同录音中抽取以及后续增加其他鸟类录音。

随后，将使用 BirdNET-Analyzer 提取音频嵌入，并基于这些嵌入训练轻量级分类模型。初始阶段会训练“storm_petrel / Background”二分类模型，验证数据处理流程、特征质量和模型性能。若成人/雏鸟标签能够可靠建立，则进一步扩展为 adult / chick / Background 或 adult / chick 二分类实验。

使用的软件和工具包括 Python、BirdNET-Analyzer、librosa、soundfile、pandas、scikit-learn 或 BirdNET 自带训练工具。项目代码将分为数据处理、模型训练和结果分析三个部分，以保证流程可复现。

模型评估将使用独立测试集完成，指标包括 precision、recall、F1-score、AUPRC 和 AUROC。除整体指标外，还会检查错误分类样本，分析模型是否容易把背景噪声、其他鸟声或低质量录音误判为风暴海燕。
